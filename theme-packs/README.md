# KAI Board Theme Extensions

Theme packs are UTF-8 JSON files downloaded separately by the user over HTTPS. Included examples are `pastel-forest.json`, `pastel-pink.json`, and `retro-japanese-manga.json`.

- Required palette colors: `background`, `key`, `specialKey`, `pressed`, `text`, `hint`, `accent`.
- Optional: `actionKey`, a 2–4 color `gradient`, and `fontFamily`.
- Allowed fonts: `sans-serif`, `sans-serif-rounded`, `serif`, and `monospace`.
- A pack is limited to 64 KB and contains no executable code or images.
- Open **Bộ màu bàn phím → Tùy chỉnh → Nhập file JSON** to install a local pack. Installed packs can be previewed, exported, shared, or deleted from the same screen.
- The current schema controls colors, gradients, and a system font family. It does not embed images or per-key artwork.
